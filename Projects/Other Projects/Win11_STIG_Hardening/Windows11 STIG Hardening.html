Project Overview

This project documents a Windows 11 security hardening workflow using Nessus scan results, DISA STIG guidance, manual remediation evidence, and PowerShell automation. I first scanned the Windows 11 VM, identified failed STIG controls, and manually fixed 10 selected controls while recording video evidence of the remediation process.

The next phase focuses on building one PowerShell script to automate 10 additional STIG fixes, then validating the results with commands and a follow-up Nessus scan to determine whether the findings are resolved or still appear.

The page is designed to look like a mix of a Nessus dashboard, Windows 11 security console, and terminal-based remediation lab.

Remediation Workflow

1

Baseline Nessus Scan

Run an authenticated scan against the Windows 11 VM to identify failed STIG controls and security configuration gaps.

2

Manual Remediation Video

Manually fix 10 selected controls and record video evidence showing the configuration path, setting change, and remediation process.

3

PowerShell Automation Build

Create one PowerShell script to remediate 10 additional STIG controls using registry changes, audit policy commands, security settings, and validation output.

4

Validation and Rescan

Run validation commands, reboot if needed, and rescan with Nessus to confirm whether the manual and scripted controls pass or still appear as findings.

Manual Fixes Completed

These 10 controls were remediated manually and captured on video as hands-on proof before moving into PowerShell automation.

WN11-CC-000285

Require secure RPC communication for Remote Desktop Session Host.

WN11-AU-000510

Configure System event log size to 32768 KB or greater.

WN11-AC-000010

Set account lockout threshold to three or fewer invalid attempts.

WN11-SO-000190

Prevent DES and RC4 Kerberos encryption suites.

WN11-CC-000280

Always prompt for password upon Remote Desktop connection.

WN11-CC-000110

Prevent printing over HTTP.

WN11-CC-000155

Disable Solicited Remote Assistance.

WN11-CC-000204

Limit enhanced diagnostic data for Windows Analytics.

WN11-CC-000090

Reprocess registry policy even when Group Policy objects have not changed.

WN11-SO-000070

Set machine inactivity limit to 900 seconds or less.

Key Takeaway

This project shows how vulnerability management is more than running a scanner. It requires understanding the finding, applying the correct configuration change, validating the system state, and rescanning to confirm the risk was actually reduced.

It also demonstrates why PowerShell matters in security operations: the same fix can be tested once, documented clearly, and repeated across systems more efficiently than manual clicking.
