File telemetry. Process evidence. Network activity. Endpoint response.

A Microsoft Defender for Endpoint threat hunting investigation focused on detecting unauthorized TOR Browser installation and usage on joseph-n-vm through file, process, and network telemetry.

Threat Scenario

Management suspected that employees may be using TOR browsers to bypass network security controls because recent network logs showed unusual encrypted traffic patterns and connections to known TOR entry nodes.

The goal of this threat hunt was to determine whether TOR Browser was installed or used on the workstation joseph-n-vm, analyze the related endpoint evidence, and document response actions if unauthorized use was confirmed.

Detection Focus

The investigation focused on TOR-related file activity, process execution, and outbound network connections over known TOR-related ports.

Investigation Snapshot

Endpoint

Workstation investigated: joseph-n-vm, onboarded to Microsoft Defender for Endpoint.

Hunting Method

Used Advanced Hunting and KQL to identify file, process, and network indicators.

Response

Confirmed TOR usage, isolated the endpoint, and notified the user's direct manager.

IoC Discovery Plan

DeviceFileEvents

Search for TOR-related files such as tor.exe, firefox.exe, and TOR Browser paths.

DeviceProcessEvents

Identify process execution, parent-child activity, and folder paths that indicate TOR Browser usage.

DeviceNetworkEvents

Review outbound connections from TOR-related processes and look for known TOR ports such as 9001.

KQL Queries Used

File Evidence

Search for TOR file events

DeviceFileEvents
| where DeviceName == "joseph-n-vm"
| where FileName == "tor.exe"
| order by TimeGenerated desc

Process Evidence

Search for TOR process execution

DeviceProcessEvents
| where DeviceName == "joseph-n-vm"
| order by TimeGenerated desc
| where InitiatingProcessFolderPath contains "tor"
| project TimeGenerated, DeviceName, AccountName, ActionType,
FileName, InitiatingProcessFolderPath

Network Evidence

Search for TOR network activity

DeviceNetworkEvents
| where DeviceName == "joseph-n-vm"
| where InitiatingProcessFileName == "tor.exe"
| order by TimeGenerated desc
| project TimeGenerated, ActionType, DeviceName,
InitiatingProcessAccountName, InitiatingProcessFileName, RemoteIP,
RemotePort
