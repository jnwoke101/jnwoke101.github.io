Project Overview

Secure Cloud Storage with Azure Key Vault & Encryption

Objective

  • Encrypt sensitive data at rest using Customer-Managed Keys (CMK) with Azure Key Vault.
  • Enforce secure data in transit using HTTPS and TLS 1.2+.
  • Implement least-privilege access using Azure Role-Based Access Control (RBAC).
  • Enable diagnostic logging and trigger alerts for key access anomalies.

Outcome

The project successfully demonstrated how to implement secure, monitored, and compliant cloud storage using native Azure capabilities. All configurations adhered to best practices for encryption, identity management, and alerting.

Tools Used

Azure Active Directory / Entra ID:

Managed user identities and access through security groups.

Azure Monitor:

Tracked unusual or denied access attempts and issued alerts.

Azure Log Analytics:

Centralized diagnostic logs for monitoring and analysis.

KQL:

Queried logs and built precise alert logic.

Managed Identity:

Supported passwordless service access to Key Vault.

Azure RBAC:

Applied secure role assignments to users and groups.

Steps Taken

Step 01

User and Identity Setup

Established user accounts and groups in Azure Active Directory to mirror department roles and enforce granular RBAC access.

Step 02

Key Vault Configuration

Created a Key Vault with soft-delete and purge protection, then generated a Customer-Managed Key named StorageEncryptionKey.

Step 03

Managed Identity Deployment

Set up StorageEncryptionIdentity for secure, passwordless interaction with encryption services.

Step 04

Storage Account Setup

Configured secure Azure Storage with CMK encryption and HTTPS-only access.

Step 05

Logging and Monitoring

Forwarded Key Vault and Storage Account diagnostic logs to a Log Analytics Workspace.

Step 06

Alerting

Created Azure Monitor alerts for abnormal activity and configured Action Groups for email notifications.

Takeaway

This project showcases real-world skills in implementing defense-in-depth security using the Azure ecosystem. It emphasizes identity-based access, managed encryption, monitoring, and alerting, which are critical components of enterprise cloud security solutions.
